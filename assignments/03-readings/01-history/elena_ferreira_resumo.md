# Resumo – História e Evolução do Java

## Evolução das linguagens de programação

As linguagens de programação evoluem para se adaptar às novas necessidades da computação e para implementar melhorias em relação às linguagens anteriores.

## A importância da linguagem C

A linguagem **C** teve um impacto enorme na história da programação, pois mudou fundamentalmente a forma como os programas eram pensados e desenvolvidos.

Ela surgiu da evolução das linguagens:

**BCPL → B → C**

com o objetivo de substituir o uso intenso de **Assembly** na criação de sistemas.

Por isso, C era frequentemente descrita como:

> “Uma linguagem feita por programadores para programadores.”

## Surgimento da Programação Orientada a Objetos

Com o aumento da complexidade dos programas, surgiu a necessidade de novos paradigmas de organização de código. Isso levou ao desenvolvimento da **Programação Orientada a Objetos (POO)** e ao surgimento do **C++**, que adicionou esse paradigma à base da linguagem C.

## Criação do Java

Mais tarde, **Java** foi criado para atender novas necessidades da computação, principalmente a execução de programas em **diferentes sistemas, computadores e arquiteturas**.

Inicialmente, Java foi desenvolvido para **dispositivos eletrônicos embarcados**, com foco em **portabilidade de código**. Com o crescimento da internet, a linguagem passou a ser amplamente utilizada no desenvolvimento de **aplicações web**.

## Portabilidade do Java

Uma das principais características do Java é sua **portabilidade**, possibilitada pelo **bytecode**.

Quando um programa Java é compilado, ele **não gera código específico para um sistema operacional**. Em vez disso, gera **bytecode**, que é executado pela **Java Virtual Machine (JVM)**.

Isso significa que **qualquer computador que tenha uma JVM pode executar o mesmo programa**, independentemente do sistema operacional.

Esse conceito ficou conhecido pelo slogan:

> **"Write once, run anywhere."**

## Inovações do Java

### Applets
Uma das primeiras inovações do Java foram os **applets**, que permitiam a criação de **páginas web interativas** executando programas diretamente no navegador.

### Segurança

Java também introduziu um **modelo de segurança robusto**. Programas baixados da internet eram executados em um ambiente restrito chamado **sandbox**, que limita o acesso do código ao sistema e aumenta a segurança.
